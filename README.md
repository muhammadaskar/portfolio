- Contact information

## Technologies Used

- JavaScript

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/muhammadaskar/portfolio.git
```

2. Navigate to the project directory
```bash
cd portfolio
```

3. Open `index.html` in your browser
